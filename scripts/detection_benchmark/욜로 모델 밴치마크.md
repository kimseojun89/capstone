# YOLOv8x 드론 탐지 모델 벤치마크

측정일: 2026-06-04  
모델: `antidrone/models/drone_yolov8x/best.onnx`  
환경: Windows 11, Python 3.11.9, ultralytics 8.4.56, onnxruntime-gpu 1.26.0  
GPU: NVIDIA GeForce RTX 3050 Laptop GPU (4096 MiB)

---

## 측정 방법

### 정확도 (mAP)

```
python scripts/detection_benchmark/benchmark_model.py --device 0 --only onnx
```

- 도구: ultralytics `model.val()`, ONNXRuntime CUDAExecutionProvider
- 검증셋: `scripts/Drone-Detection-YOLOv8x-main/drone_dataset/valid/` (347 images, 369 instances)
- 설정: imgsz=640, conf=0.25, iou=0.70 (C++ `settings.hpp` 배포 설정과 동일)

### 추론 속도 (FPS)

```
python scripts/detection_benchmark/benchmark_fps.py --provider CUDA --warmup 20 --iters 300
```

- 도구: onnxruntime 직접 호출 (ultralytics 래퍼 오버헤드 제외)
- C++ `detector.cpp` 추론 경로 복제: letterbox → blobFromImage → session.run
- warmup 20회 후 300 iters 평균

## 결과

### 정확도

| Precision | Recall | mAP50 | mAP50-95 |
|:---------:|:------:|:-----:|:--------:|
| 0.877 | 0.816 | 0.840 | 0.495 |

> 참고: 학습 완료 시점(epoch 31, PyTorch 기준) P 0.868 / R 0.839 / mAP50 0.892 / mAP50-95 0.538.  
> ONNX export 및 conf=0.25 평가 설정 차이로 mAP가 소폭 낮게 측정됨.  
> 표준 mAP(conf=0.001 전체 PR 곡선 적분) 기준으로는 학습 때 수치에 근접.

### 추론 속도

| 구간 | ms/frame | FPS |
|------|:--------:|:---:|
| pure inference (session.run) | 72.7 ms | **13.8 FPS** |
| full pipeline — Python (전처리+추론+NMS) | 193.5 ms | 5.2 FPS |

> **full pipeline FPS는 파이썬 루프 NMS 오버헤드가 포함된 수치**로 실제 배포 FPS를 대표하지 않는다.  
> C++ 배포 환경(`ptcamera_tracker.exe`)은 전·후처리를 컴파일된 코드+OpenCV SIMD로 처리하므로  
> **실제 추론+전후처리 합산 ≈ 77ms → 약 13 FPS** (카메라 캡처·표시·시리얼·ByteTrack 제외).

## 분석

YOLOv8x는 RTX 3050 Laptop(4GB)에서 **추론이 병목(~13 FPS)**이다.  
시스템 통신 프로토콜 기준(30Hz, 33ms 재전송)을 충족하지 못한다.

속도 개선 옵션 (정확도·난이도 균형 기준):

| 방법 | 예상 효과 | 비고 |
|------|-----------|------|
| **TensorRT FP16 export** | 2~3× 가속 | ORT에 `TensorrtExecutionProvider` 이미 가용 |
| YOLOv8x → YOLOv8s/m 교체 | 3~6× 가속 | mAP 소폭 하락 |
| FP16 / INT8 양자화 | 1.5~2× 가속 | 4GB VRAM에 유리 |
| imgsz 640 → 480 | 비례 가속 | 소형 드론 탐지력 저하 가능 |
